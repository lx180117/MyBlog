关系说明

关系基数业务含义
USERS → ARTICLES一对多一个作者可写多篇；作者有文章时不可删除（RESTRICT）
USERS → COMMENTS一对多登录用户的评论；账号删除后评论降级为匿名（SET NULL）
CATEGORIES → ARTICLES一对多一篇文章归属一个分类；分类删除后文章变未分类（SET NULL）
ARTICLES ↔ TAGS多对多经 article_tags 中间表；任一删除都级联清理
ARTICLES → COMMENTS一对多文章下的全部评论，两级结构
COMMENTS → COMMENTS自关联parent_id 为空即顶级评论，非空即回复；触发器禁止三级
ARTICLES → ARTICLE_LIKES一对多UNIQUE(article_id, ip_address) 是防重复点赞的依据
ARTICLES → PAGE_VIEWS一对多阅读明细，用于趋势统计与后续分区

删除策略一览

外键策略理由
articles.author_idRESTRICT有文章就不让删账号，强制走"禁用"而非物理删除
articles.category_idSET NULL删分类不该连坐文章
article_tags / article_likesCASCADE纯关联表，无独立价值
comments.article_idCASCADE文章删了评论无意义
comments.user_idSET NULL删账号后评论转为匿名，内容不丢
comments.parent_idCASCADE父评论删除时回复一并清理
