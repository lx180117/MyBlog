# 博客平台 · 接口清单（Step 5 交付）

> 版本：1.0.0 ｜ 日期：2026-09-17
> 机器可读版本：`server/openapi.json`（由 `npm run openapi:export` 生成，是 Step 6 生成前端的输入）
> 交互式文档：后端启动后访问 `/api/v1/docs`

**全局约定**

| 项 | 约定 |
| --- | --- |
| 前缀 | `/api/v1`（`sitemap.xml`、`robots.txt`、`rss.xml`、`health` 不带前缀） |
| 认证 | `Authorization: Bearer <accessToken>`；Access 15 分钟、Refresh 7 天 |
| ID | 一律用**字符串**收发（数据库是 BIGINT，JS Number 超过 2^53 会丢精度） |
| 分页 | 列表统一返回 `{ items, total, page, pageSize, totalPages }` |
| 错误 | `{ statusCode, error, message, path, timestamp }`，`message` 可能是字符串或字符串数组 |
| 角色 | `admin` / `author`；写操作额外要求账号 `status = active` |

---

## 1. 认证（`/auth`）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/auth/register` | 公开 | 注册。限流 5 次/分钟。返回 `pending` 状态的账号与令牌 |
| POST | `/auth/login` | 公开 | 用户名或邮箱登录。限流 10 次/分钟，连续失败 5 次锁定 15 分钟 |
| POST | `/auth/refresh` | 公开 | 用 Refresh Token 换新令牌对 |
| GET | `/auth/me` | 登录 | 当前用户 + `canPublish`（是否已激活可发文） |
| PATCH | `/auth/me` | 登录 | 更新昵称、头像、简介、社交链接、邮箱 |
| POST | `/auth/me/password` | 登录 | 修改自己的密码（需当前密码） |
| POST | `/auth/logout` | 登录 | 登出（无状态 JWT：前端清本地令牌即可） |

## 2. 文章 · 前台（`/articles`）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/articles` | 公开 | 列表。支持 `keyword`、`categorySlug`、`tagSlug`、`authorUsername`、`year`/`month`、`sort`（latest/oldest/hot/comments） |
| GET | `/articles/archives` | 公开 | 按年月归档（数据库内聚合） |
| GET | `/articles/:slug` | 公开 | 详情。带 Token 时回填 `likedByMe`、`canEdit`；草稿仅作者与管理员可见 |
| POST | `/articles/:id/view` | 公开 | 阅读量 +1。同 IP 同文章 10 分钟去重 |
| POST | `/articles/:id/like` | 公开 | 点赞。按 IP + 文章去重，幂等 |
| DELETE | `/articles/:id/like` | 公开 | 取消点赞，幂等 |

## 3. 文章 · 作者工作台（`/me/articles`）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/me/articles` | 作者 | 我的文章（含草稿）。管理员可带 `all=true` 看全站 |
| GET | `/me/articles/stats` | 作者 | 总数 / 已发布 / 草稿 / 回收站 / 定时中 |
| GET | `/me/articles/:id` | 作者 | 编辑器回填，草稿也能取到 |
| POST | `/me/articles` | 作者 + 已激活 | 新建。自动生成 slug、摘要、渲染 HTML 缓存 |
| PATCH | `/me/articles/:id` | 作者 + 已激活 | 更新 |
| PATCH | `/me/articles/:id/publish` | 作者 + 已激活 | 发布；传未来时间即为定时发布 |
| PATCH | `/me/articles/:id/unpublish` | 作者 + 已激活 | 撤回为草稿 |
| PATCH | `/me/articles/:id/top` | 作者 + 已激活 | 置顶 / 取消置顶 |
| DELETE | `/me/articles/:id` | 作者 + 已激活 | 软删除进回收站 |
| POST | `/me/articles/:id/restore` | 作者 + 已激活 | 从回收站恢复（回到草稿态） |

## 4. 文章 · 管理员（`/admin/articles`）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/admin/articles` | 管理员 | 全站文章，可按作者与状态筛选 |
| DELETE | `/admin/articles/:id/purge` | 管理员 | 彻底删除，不可恢复（级联清理评论/点赞/访问记录） |

## 5. 评论

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/articles/:articleId/comments` | 公开 | 已通过的评论，顶级评论分页、回复随附 |
| POST | `/articles/:articleId/comments` | 公开 | 提交评论。登录用户自动关联账号，游客需填昵称。同 IP 60 秒限一条 |
| GET | `/admin/comments` | 作者/管理员 | 审核列表。作者只见自己文章下的评论 |
| GET | `/admin/comments/stats` | 作者/管理员 | 待审 / 通过 / 拒绝 / 今日 |
| PATCH | `/admin/comments/:id/approve` | 作者/管理员 | 通过 |
| PATCH | `/admin/comments/:id/reject` | 作者/管理员 | 拒绝 |
| POST | `/admin/comments/batch` | 作者/管理员 | 批量通过 / 拒绝 / 删除（单次 ≤100，逐条校验归属） |
| DELETE | `/admin/comments/:id` | 作者/管理员 | 删除 |
| GET | `/me/comments` | 作者 | 我文章下的评论（等价于上面的作者视图） |

## 6. 分类与标签

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/categories` | 公开 | 分类列表（含前台可见文章数） |
| GET | `/tags` | 公开 | 标签列表（含文章数） |
| POST | `/admin/categories` | 管理员 | 新建分类 |
| PATCH | `/admin/categories/:id` | 管理员 | 修改分类 |
| DELETE | `/admin/categories/:id` | 管理员 | 删除。文章变为「未分类」，不会连带删除 |
| POST | `/admin/tags` | 管理员 | 新建标签 |
| POST | `/admin/tags/merge` | 管理员 | 合并标签（清理同义标签） |
| DELETE | `/admin/tags/:id` | 管理员 | 删除标签 |

## 7. 作者主页

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/authors/:username` | 公开 | 作者资料（含文章数、累计阅读与点赞）+ 其文章列表 |

## 8. 用户管理（`/admin/users`）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/admin/users` | 管理员 | 列表。待审核排最前 |
| GET | `/admin/users/stats` | 管理员 | 总数 / 待审 / 激活 / 禁用 / 管理员 / 今日注册 |
| GET | `/admin/users/:id` | 管理员 | 详情 |
| PATCH | `/admin/users/:id/status` | 管理员 | 审核激活 / 禁用 / 退回待审 |
| PATCH | `/admin/users/:id/role` | 管理员 | 调整角色 |
| POST | `/admin/users/:id/reset-password` | 管理员 | 重置密码；不传新密码则生成 12 位随机密码并返回 |
| DELETE | `/admin/users/:id` | 管理员 | 删除（仅有零篇文章的账号可删） |
