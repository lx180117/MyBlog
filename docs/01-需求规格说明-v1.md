## 1. 项目定位

一个**以 Markdown 写作为核心**的个人/团队内容发布平台。核心诉求排序：

1. **写作顺畅** —— 作者只需专注写 Markdown，其余（排版、目录、代码高亮）自动完成。
2. **访问体验好** —— 移动端可读、首屏快、支持暗黑模式。
3. **被搜索引擎收录** —— 具备基础 SEO 能力（meta、sitemap、RSS）。
4. **运营成本低** —— 能长期用低成本方案自托管，不被平台绑定，数据可导出。

非目标：不做社区化运营（关注/私信/积分）、不做电商、不做多租户 SaaS。

## 2. 角色与权限

| 角色 | 说明 | 权限范围 |
| --- | --- | --- |
| 访客 Visitor | 未登录用户 | 浏览文章、按分类/标签筛选、搜索、提交评论 |
| 作者 Author | 内容生产者 | 访客全部权限 + 管理**自己**的文章与草稿 |
| 管理员 Admin | 站点负责人 | 全站配置、用户管理、评论审核、数据统计 |

`[默认]` **v1 只做「单管理员」模型**：不开放注册，作者与管理员为同一人。数据库仍预留角色字段，后续开放多作者时不需要改表结构。

## 3. 功能需求

### FR-1 内容管理

- **FR-1.1** 文章增删改查：标题、正文（Markdown）、封面图、摘要
- **FR-1.2** 编辑体验：Markdown 源码编辑 + 实时预览，支持代码块语法高亮、图片粘贴上传
- **FR-1.3** 状态流转：`草稿 draft → 已发布 published → 回收站 deleted`（软删除，可恢复）
- **FR-1.4** 定时发布：指定未来时间自动转为已发布
- **FR-1.5** 置顶与推荐位
- **FR-1.6** 摘要自动生成：未填写时从正文截取前 N 字
- **FR-1.7**（v1.5 可选）版本历史与回滚

### FR-2 分类与标签

- **FR-2.1** 分类：单层级，`[默认]` 一篇文章归属**一个**分类
- **FR-2.2** 标签：多对多，一篇文章可挂多个标签
- **FR-2.3** 归档视图：按年 / 月聚合，展示时间线
- **FR-2.4** 分类与标签下均有独立列表页

### FR-3 评论与互动

- **FR-3.1** 评论提交：昵称、邮箱（不公开）、站点、内容
- **FR-3.2** 两级结构：评论 + 对评论的回复（不做无限嵌套，避免 UI 复杂与审核困难）
- **FR-3.3** 审核流：`待审核 pending / 已通过 approved / 已拒绝 rejected`，`[默认]` 新评论一律待审核
- **FR-3.4** 反垃圾：同 IP 提交频率限制、简易敏感词过滤、可选验证码
- **FR-3.5** 文章点赞：单篇维度计数，`[默认]` 按 IP + 文章去重

### FR-4 检索

- **FR-4.1** 关键词搜索：覆盖标题与正文
- **FR-4.2** 结果分页、按分类/标签筛选、按发布时间排序
- **FR-4.3** `[默认]` 使用**数据库原生全文能力**（PostgreSQL `tsvector` 或 MySQL `FULLTEXT`），v1 不引入 Elasticsearch/Meilisearch

### FR-5 用户与认证

- **FR-5.1** 管理员登录：账号 + 密码，密码用 bcrypt/argon2 哈希存储
- **FR-5.2** 会话：JWT（Access Token + Refresh Token），支持后台主动失效
- **FR-5.3** 登录失败次数限制

### FR-6 后台管理

- **FR-6.1** 仪表盘：文章总数、待审评论数、阅读量趋势（近 7/30 天）
- **FR-6.2** 内容管理：文章列表 / 编辑器 / 分类 / 标签
- **FR-6.3** 评论管理：批量通过、拒绝、删除
- **FR-6.4** 站点设置：站点名、Logo、备案信息、社交链接、每页文章数、评论开关

### FR-7 站点展示与 SEO

- **FR-7.1** 前台页面：首页文章流、文章详情页、分类页、标签页、归档页、搜索页、关于页
- **FR-7.2** 响应式布局：桌面 / 平板 / 手机三档
- **FR-7.3** 暗黑模式，跟随系统 + 手动切换
- **FR-7.4** 文章详情页自动生成目录（TOC）
- **FR-7.5** SEO：每页 `title`/`description`、文章页 Open Graph、`sitemap.xml`、`robots.txt`
- **FR-7.6** RSS / Atom 订阅输出
- **FR-7.7** 阅读量统计：单篇 PV 计数 + 简易访问日志

## 4. 非功能需求

| 维度 | 指标 |
| --- | --- |
| 性能 | 文章列表接口 P95 < 300ms；首屏可交互 < 2s；列表分页每页 ≤ 20 条 |
| 安全 | 密码哈希、JWT 校验、参数化查询、评论内容转义（防 XSS）、后台接口鉴权、上传文件类型与大小校验 |
| 可维护 | 分层清晰（Controller / Service / Repository）、接口文档化（OpenAPI 3）、数据库变更可迁移 |
| 可靠性 | 数据库可定时备份；文章内容可导出为 Markdown 文件 |
| 成本 | `[默认]` 优先免费额度或单台低配服务器，月成本控制在 0～100 元 |
| 数据量 | `[默认]` 假设 ≤ 1000 篇文章、≤ 1000 PV/日、评论 ≤ 1 万条 |

## 5. 关键数据实体（Step 4 将展开为 DDL）

| 实体 | 说明 | 主要关系 |
| --- | --- | --- |
| `user` | 账号（v1 仅管理员） | 1 : N `article` |
| `article` | 文章 | N : 1 `category`，N : N `tag` |
| `category` | 分类 | 1 : N `article` |
| `tag` | 标签 | N : N `article` |
| `article_tag` | 文章-标签关联表 | 多对多中间表 |
| `comment` | 评论 | N : 1 `article`，自关联 `parent_id` 实现两级回复 |
| `site_setting` | 站点配置（键值对） | 独立 |
| `page_view` | 访问/阅读记录 | N : 1 `article` |
